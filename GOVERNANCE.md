# Governance

NetNavr is currently maintainer-led while its first product and safety contracts
are being validated.

## Decisions

- The repository owner is responsible for releases, security response, project
  direction, and changes to governance.
- Technical decisions should be recorded in public issues or pull requests when
  possible, with alternatives and verification evidence.
- Maintainer status is earned through sustained, constructive contribution and
  is not implied by a single accepted change.

## Boundaries

The project will prioritize user control, provider replaceability, explicit
permissions, inspectable state, and safe recovery over ecosystem growth. A
capability will not be called stable until its contract and failure behavior are
testable.

This document will evolve if a contributor community forms. Governance changes
will be announced in the repository history.
