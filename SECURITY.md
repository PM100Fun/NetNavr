# Security Policy

## Supported versions

NetNavr is pre-alpha and has no supported production release. The current code
is intended only for local research with non-sensitive data.

Do not expose the development servers to untrusted networks. Do not use real
payment credentials, production funds, important personal data, or irreplaceable
memory with this prototype.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository
instead of opening a public issue. Include affected components, reproduction
steps, impact, and any suggested mitigation. If private reporting is not yet
available, contact the repository owner privately through the public GitHub
profile and avoid publishing exploit details until a reporting channel is
established.

We will acknowledge a usable report as soon as practical, investigate it, and
coordinate disclosure based on severity and the maturity of the project. No
bounty program is currently offered.
